# Editorial Room

Folder ini menjadi gerbang keputusan manusia.

## Status materi
- `pending/`: brief/naskah menunggu review.
- `approved/`: materi yang sudah disetujui untuk tahap berikutnya.
- `rejected/`: materi yang tidak dipakai; alasan penolakan dicatat.

## Checklist persetujuan
- [ ] Angle dan sudut pandang sudah disetujui.
- [ ] Prediksi/analisis sesuai keputusan editor.
- [ ] Fakta memiliki sumber dan tanggal.
- [ ] Rumor diberi label dan tidak ditulis sebagai fakta.
- [ ] Kondisi pemain/cedera tidak disimpulkan tanpa bukti.
- [ ] Aset visual memiliki sumber serta status izin penggunaan.
- [ ] Tidak ada klaim yang merugikan atau menyesatkan.

Persetujuan editorial tidak otomatis berarti aset visual bebas hak cipta. Pemeriksaan izin aset tetap wajib.
