# Editorial Room

Folder ini menjadi gerbang keputusan manusia.

## Dua jalur editorial

### A. Prediksi Starting XI — jalur cepat berbasis riset
Untuk prediksi susunan pemain pertandingan Persib, editor cukup meminta asisten menyiapkan riset dan analisis terkini. Tidak perlu mengisi Selection Template panjang. Ikuti pedoman di STARTING-XI-PLAYBOOK.md.

Asisten wajib memeriksa jadwal, kondisi/cedera/skorsing pemain, potensi rotasi, jadwal lanjutan, dan kebutuhan taktik lawan. Semua status yang belum jelas harus ditandai belum terkonfirmasi. Hasilnya adalah prediksi, bukan lineup resmi. Editor tetap memberi masukan dan menyetujui angle sebelum produksi.

### B. Topik lain — seleksi editorial normal
- pending/: brief/naskah menunggu review.
- approved/: materi yang sudah disetujui untuk tahap berikutnya.
- rejected/: materi yang tidak dipakai; alasan penolakan dicatat.

## Checklist persetujuan
- [ ] Angle dan sudut pandang sudah disetujui.
- [ ] Prediksi/analisis sesuai keputusan editor.
- [ ] Fakta memiliki sumber dan tanggal.
- [ ] Rumor diberi label dan tidak ditulis sebagai fakta.
- [ ] Kondisi pemain/cedera tidak disimpulkan tanpa bukti.
- [ ] Aset visual memiliki sumber serta status izin penggunaan.
- [ ] Tidak ada klaim yang merugikan atau menyesatkan.

Persetujuan editorial tidak otomatis berarti aset visual bebas hak cipta. Pemeriksaan izin aset tetap wajib.

## Alur seleksi topik selain prediksi XI
1. Buka research/daily/latest.md dan pilih kandidat yang menarik.
2. Salin SELECTION-TEMPLATE.md menjadi file baru di editorial/pending/ dengan nama topik dan tanggal.
3. Buka sumber asli, catat status tiap klaim, lalu isi angle, hook, konteks, dan kebutuhan visual.
4. Hanya editor yang boleh mengubah status menjadi APPROVED FOR SCRIPT.
5. Persetujuan ini hanya membuka tahap penulisan draf; render dan publikasi tetap memerlukan QC serta persetujuan terpisah.

Catatan: skor prioritas di news monitor hanya alat triase berbasis judul/sumber feed. Jangan gunakan skor itu sebagai ukuran akurasi atau dasar tunggal memilih berita.
