# FCC Chibi — Rigging Preparation

## Purpose
Prepare the approved FCC chibi host for a reusable 2D puppet. This stage creates isolated, transparent head and body base layers from the canonical vector master. It does not yet claim to be a finished rig or animated presenter.

## Canonical identity (do not redesign)
- Dark Bandung Casuals × gorpcore parka.
- Cargo pants and outdoor/retro sneakers.
- Permanent circular FLOWER CITY CASUALS sleeve patch with Persib identity in the center.
- Blue Persib accents.
- Preserve the approved proportions, hair silhouette, skin tone, and friendly facial style.

## Current source assets
- `assets/chibi/master-sheet.svg` — canonical vector master.
- `assets/chibi/expressions/` — six exported pose/expression references (normal, senang, analisis, marah, kaget, kecewa).
- `assets/chibi/rigging/` — isolated head/body base layers generated by `scripts/prepare_chibi_rigging.py`.

## Rigging map (first pass)
| Layer | Pivot / anchor | Motion |
|---|---|---|
| Head | Neck center, approximately (0, 0) in local head coordinates | Nod, tilt, small rotation |
| Body | Waist / pelvis center | Subtle lean and bounce |
| Left arm | Left shoulder | Gesture; separate from torso in a later pass |
| Right arm | Right shoulder | Gesture; separate from torso in a later pass |
| Eyes | Face-local coordinates | Blink; separate layer still required |
| Mouth | Face-local coordinates | Viseme swaps for lip-sync; separate layer still required |

## Important limitations
The current master is a vector character sheet, not a layered animation source. The first isolation pass extracts only head and body base components. Arms are still part of the body symbol; eyes and mouth are still embedded in the head symbol. Do not describe this output as full skeletal rigging or lip-sync-ready.

## Next production gates
1. Verify the generated head/body PNGs have transparent backgrounds, correct framing, and no clipping.
2. Split left/right arms and hands into independent layers with shoulder pivots.
3. Split eyes (open/closed) and mouth shapes (rest, A, I, U, E, O) into independent layers.
4. Assemble a puppet in a 2D animation tool and test head turns, blinks, gestures, and Indonesian lip-sync.
5. Render a 5–10 second presenter test, then review character consistency before integrating into the video template.

## Reproducible export
Run `python scripts/prepare_chibi_rigging.py` after installing `requirements-chibi.txt`.
